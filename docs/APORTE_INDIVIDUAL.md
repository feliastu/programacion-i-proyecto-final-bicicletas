# Registro del aporte individual

**Estudiante responsable:** Hernan Felipe Astudillo Peña (`feliastu`).

El proyecto final se presenta de forma individual. Su alcance comprende el modelo
de mantenimiento de bicicletas, la implementación de las órdenes y su bitácora,
las cuatro excepciones del dominio, la demostración polimórfica y las pruebas.

La implementación y la documentación se registran en commits separados del mismo
proyecto. El historial de GitHub identifica los cambios relacionados con AC3;
la etiqueta Entrega_AC3 señala la versión preparada para entrega.

Se utilizó ChatGPT para analizar el enunciado, proponer y desarrollar el diseño,
escribir y ejecutar las pruebas, elaborar el UML y preparar los documentos. La
asistencia y las propuestas descartadas se describen en el Documento de Decisiones
de Diseño. Este registro no presenta la implementación asistida como trabajo
realizado sin apoyo ni acredita una sustentación personal ya efectuada.
